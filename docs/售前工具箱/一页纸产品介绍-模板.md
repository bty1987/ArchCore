## 【ArchCore 客户消息归档系统】

**一句话：让每一条客户消息，都变成企业可以理解和经营的业务资产。**

### 您是否遇到过

- 客户在微信群里说了需求，三天后没人找得到那条消息；
- 员工离职，客户沟通记录跟着走，接手的人两眼一抹黑；
- 老板问"这个客户聊到哪了"，答案靠员工回忆。

### 系统能力（当期版本）

| 能力 | 说明 |
|---|---|
| **全量归档** | 历史消息一次导入 + 新消息自动增量，白名单业务群/客户单聊 |
| **秒级检索** | 按客户、关键词、时间、发送者找任何一段对话 |
| **客户档案** | 微信群自动映射到客户档案，沟通历史一页看全 |
| **主动预警** | 响应超时、投诉、报价、竞品提及→实时推送到企业微信 |
| **基础分析** | 消息量趋势、响应时长、成员活跃 |

> 🔒 **数据边界（我们的卖点，也是您的底线）**：系统部署在**您自己的电脑/内网**，数据全程不离开您的服务器，我们不带走、不留存、不外传；系统只收不发，不做任何自动群发、加好友类操作。

### 交付方式

内网部署交付（目标 1 周内完成）：历史导入 → 群-客户映射工作坊 → 培训 → 试运行 → 验收。含账号备用方案与版本维护服务。
