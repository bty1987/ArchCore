## 1. 文档定位

既有文档链对**封号风险**（平台侧）已有完整处置，但对商用更硬的门槛——**客户方群成员作为第三方个人信息主体的合规基础**——此前只有一句话带过。本方案补齐这块：界定角色、给出可执行的告知/最小化/权限措施、明确合同条款要点与商业化前必须完成的评估项。

> 本方案是内部风险管理文档，不构成法律意见；正式商用前应请法务或外部律师按目标客户所在地法规复核。

## 2. 角色与数据主体

| 角色 | 谁 | 定位 |
|---|---|---|
| 个人信息处理者 | 使用本系统的客户企业 | 决定采集范围与用途、承担告知与保护义务的主体 |
| 受托处理者 | 我方（交付与运维服务） | 按合同约定处理数据，不得超范围使用，不得留存 |
| 数据主体① | 客户方群成员（甲方联系人等第三方个人） | 被归档、检索、画像与分析的核心第三方主体 |
| 数据主体② | 我方员工（含采集号实名归属人） | 知情与最小化义务的对象 |

关键认知：**会话数据的高敏性不止在「员工被监控」，更在「第三方自然人的聊天被企业留存分析」**。员工知情只是两半中的一半，此前文档只覆盖了这一半。

## 3. 风险清单

| # | 风险 | 等级 | 对应措施 |
|---|---|---|---|
| 1 | 客户方成员不知情：其发言被归档、检索、画像 | 高 | 4.1 告知 + 4.2 最小化 |
| 2 | 采集超范围：非业务会话（员工个人社交）入库 | 高 | 4.2 白名单（PRD F1-6，采集端过滤） |
| 3 | 分析与展示越权：sales 可见非负责客户、导出失控 | 中 | 4.3 权限与审计 |
| 4 | 数据外泄：备份/导出/演示环节 | 中 | 4.4 数据边界 + 演示数据合成红线 |
| 5 | 委托处理瑕疵：我方运维接触数据无合同约束 | 中 | 4.5 合同条款 |
| 6 | 退出无机制：客户停用后数据未妥善移交 | 中 | 4.6 生命周期 |

## 4. 措施

### 4.1 告知（对数据主体①）

- **入群告知（推荐主路径）**：业务群建立/接入时的群公告模板：「本群沟通记录将用于项目服务质量管理与内部留存」。话术模板随交付包提供，配置为可选项；
- **告知的限度要诚实**：群公告式告知可构成合理的告知基础，但不等于逐一取得同意；对齐「内部质量管理/履行合同必需」的合法性基础而非「同意」，具体口径由法务复核确定；
- **禁止事项**：不将客户方成员的个人特征（健康、家庭等敏感属性）作为分析对象；风险词/关注词库仅限业务语义（投诉、竞品、报价类）。

### 4.2 数据最小化

- 会话白名单（PRD F1-6）：非业务群/非白名单单聊在**采集端**即被过滤，数据不出微信数据目录；
- 单聊范围：仅采集号自身的客户单聊（PRD 3.1 采集账号定位），员工个人账号不采集；
- 媒体默认存元数据 + 文件本体按保留策略归档；语音转文字（V2）上线前不处理语音内容；
- 保留策略：消息明细默认保留 24 个月（可按客户配置），到期归档压缩；导出全量审计。

### 4.3 权限与展示收敛

- RBAC：sales 仅见自己负责客户（系统设计已有，此处作为合规措施重申）；
- 撤回消息内容仅 admin 可见（PRD 3.3）；
- 客户方成员在界面以备注名/角色展示，昵称头像等个人信息不进入分析产出；
- 导出（CSV/HTML）默认仅 manager/admin，写审计日志。

### 4.4 数据边界

- 全部数据留在客户内网（部署形态天然保证）；我方远程运维时不落任何数据副本，屏幕共享脱敏；
- 演示环境一律 gen-fixtures 合成数据（运维规划 3.3 红线）；
- 备份介质加密保管（运维规划 2.4 已有）。

### 4.5 合同条款要点（对客户企业）

1. 客户确认为个人信息处理者，自行确保采集范围与告知义务的合法性基础；
2. 我方为受托处理者，仅按运维需要接触数据，服务结束不留存、销毁留痕；
3. 数据归属：全部会话数据归客户；
4. 合规配合：我方提供告知话术模板、最小化配置与权限设计的合理默认值；
5. 账号风险条款（运维规划 3.4 已有）与本方案条款并列，不混同。

### 4.6 生命周期

- 客户停用：数据全量移交（SQLite + media/）；我方侧以「从未留存」为承诺，无销毁义务即无残留风险；
- 试用转正式/终止试用的数据处理口径写入试点协议。

## 5. 商业化前必须完成的评估项（清单）

- [ ] 法务复核：入群告知话术的合法性基础口径（内部质量管理/履行合同必需）
- [ ] 告知话术模板定稿并随交付包提供
- [ ] 白名单过滤（F1-6）在 MVP 验收中作为合规项测试
- [ ] 合同模板含 4.5 全部条款
- [ ] 内部试点期间演练一次「客户方成员询问你们为什么有我的聊天记录」的应答口径
- [ ] 词库审核确认：风险词/关注词不含个人特征类词汇
